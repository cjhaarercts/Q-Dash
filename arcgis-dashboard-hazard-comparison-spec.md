# ArcGIS Dashboard Hazard Comparison Specification (DSH-05)

## Purpose

Define the DSH-05 hazard comparison panel behavior for combined and per-hazard views, including overlap-risk and provisional labeling requirements.

## Source Inputs

The panel consumes the leadership contract in `integration-api-contracts.md` section 5 and a dashboard-comparison view model (`hazardComparison`) generated by dashboard query logic.

Base contract fields:

- `eventId`
- `whoWhatWhereHowMany.what.hazards[]`
- `whoWhatWhereHowMany.howMany.*`
- `whoWhatWhereHowMany.where.overlapDistricts[]`
- `districtDetails[]`
- `deduplication.overlapDeconflicted`
- `deduplication.doubleCountRisk`

Comparison view model fields:

- `hazardComparison.combined`
- `hazardComparison.perHazard[]`
- `hazardComparison.overlapWarning`

## Panel Modes

1. Combined mode

- Show deconflicted totals across selected hazards:
  - `unaccountedFor`
  - `needingHelp`
  - `needingHelpContacted`
- Combined totals are represented by `hazardComparison.combined.counts`.

1. Per-hazard mode

- Show one row or series per hazard in current selection.
- Per-hazard totals are represented by `hazardComparison.perHazard[]`.

## Required Comparison Rules

1. Hazard coverage

- Every hazard in `whoWhatWhereHowMany.what.hazards[]` must appear exactly once in `hazardComparison.perHazard[].hazard`.

1. Count completeness

- `combined.counts` and each `perHazard[].counts` entry must provide:
  - `unaccountedFor`
  - `needingHelp`
  - `needingHelpContacted`

1. Combined ceiling rule

- Let raw per-hazard sum be the metric-wise sum of all `perHazard[].counts`.
- If `deduplication.overlapDeconflicted = true`:
  - combined count for each metric must be less than or equal to raw sum.
  - `hazardComparison.overlapWarning.provisional` must be false.
- If `deduplication.overlapDeconflicted = false`:
  - `hazardComparison.overlapWarning.provisional` must be true.
  - overlap warning banner must be visible.

1. Overlap warning visibility

- If `whoWhatWhereHowMany.where.overlapDistricts[]` is non-empty, then `hazardComparison.overlapWarning.visible` must be true.
- `hazardComparison.overlapWarning.risk` must equal `deduplication.doubleCountRisk`.

## Reference Comparison View Model

```json
{
  "hazardComparison": {
    "combined": {
      "mode": "combined",
      "counts": {
        "unaccountedFor": 47,
        "needingHelp": 12,
        "needingHelpContacted": 9
      }
    },
    "perHazard": [
      {
        "hazard": "hurricane",
        "counts": {
          "unaccountedFor": 39,
          "needingHelp": 10,
          "needingHelpContacted": 8
        }
      },
      {
        "hazard": "flood",
        "counts": {
          "unaccountedFor": 18,
          "needingHelp": 5,
          "needingHelpContacted": 3
        }
      }
    ],
    "overlapWarning": {
      "visible": true,
      "provisional": false,
      "risk": "low",
      "message": "Overlap deconflicted totals are shown."
    }
  }
}
```

## Validation Commands

```powershell
npm run dashboard:validate-contract -- <path-to-response-json>
npm run dashboard:validate-hazard-comparison -- <path-to-response-json>
```

## DSH-05 Exit Checklist

- Combined and per-hazard modes both render from configured fields.
- Per-hazard set exactly matches selected hazards.
- Combined counts never exceed raw per-hazard sums when deconfliction is true.
- Overlap warning is visible when overlap districts exist.
- Provisional label appears when deconfliction is false.
